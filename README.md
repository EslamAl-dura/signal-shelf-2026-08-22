# Signal Shelf

Signal Shelf is a release-readiness dashboard for turning operational signals into an explainable pre-deploy risk score.

## Run locally

```bash
npm install
npm run dev
```

The production build is created with `npm run build`. Linting uses the required zero-warning command.

## Features

- TanStack Router v1 code-based routes
- Validated release signal form with Zod
- English and Arabic translations with automatic RTL layout
- Persistent light and dark theme preferences
- Responsive shadcn-style UI primitives
